# Current sources on using AI

How to use current models (choosing a model and effort, prompting, agent definitions, harness design) is looked up here first, not in the academic literature, whose studies are of models long retired (CORE rule 6; the owner, 2026-11-08). Each item is a place to check, with what it is good for and when it was last checked. The pages read from it are entries of `refs.toml`, stored in `sources/<key>/`. A seat that checks a source again updates its date. A seat that finds a good new one adds it as one more item.

1. Claude Code documentation, https://code.claude.com/docs (index https://code.claude.com/docs/llms.txt). Good for: agent definitions (header fields, what loads at the start, how model and effort are resolved), workflows, tools, settings and hooks; its changelog for what each release changed. Read: `anthropic_2026_subagents`, `anthropic_2026_cc_workflows`, `anthropic_2026_cc_agents`, `anthropic_2026_cc_vs_code`, `anthropic_2026_cc_tools_reference`, `anthropic_2026_cc_changelog_agent_sections`, `anthropic_claude_code_best_practices`; the pages read 2026-11-14 for the investigation of prompt caching: `anthropic_2026_cc_prompt_caching`, `anthropic_2026_cc_subagents_2026_11_14` (the current copy of the subagents page), `anthropic_2026_cc_settings_reference`, `anthropic_2026_cc_env_vars`, `anthropic_2026_cc_costs`, `anthropic_2026_cc_model_config`, `anthropic_2026_cc_llms_txt`; the cloud and phone pages `anthropic_2026_cc_web_2026_11_13`, `anthropic_2026_cc_web_quickstart_2026_11_13`, `anthropic_2026_cc_cloud_environments_2026_11_13` (the current copies; the 2026-11-10 ones, without the date suffix, differ in the network access levels), `anthropic_2026_cc_mobile` (plans, network access levels and allowed domains, installed tools, push limits). Last checked 2026-11-10; the four cloud and phone pages read 2026-11-13.
2. Claude API documentation, the prompting and model pages, https://platform.claude.com/docs. Good for: what each model does by default and at each effort, roles, examples, thinking, and which model to choose. Read: `anthropic_2026_prompting_best_practices`, `anthropic_2026_prompting_opus_5_5`, `anthropic_2026_prompting_opus_5` (read 2026-11-14: response length, narration, positive examples over prohibitions), `anthropic_2026_prompting_sonnet_5_5`, `anthropic_2026_prompting_haiku_5_5`, `anthropic_2026_effort`, `anthropic_2026_thinking`, `anthropic_2026_thinking_steering`, `anthropic_2026_choosing_model`, `anthropic_2026_skill_best_practices`, `anthropic_2026_api_prompt_caching` (read 2026-11-14). Last checked 2026-11-08.
3. Anthropic's engineering blog, https://www.anthropic.com/engineering. Good for: how Anthropic builds agents, prompts, tools, judges and evaluations. Read: `anthropic_2024_effective_agents`, `anthropic_2025_multiagent`, `anthropic_2025_context_engineering`, `anthropic_2025_writing_tools`, `anthropic_2026_harness_design`, `anthropic_2026_demystifying_evals`. Last checked 2026-11-08.
4. Boris Cherny on X, @bcherny, who created Claude Code. Good for: the Claude Code team's own practice. Read: `cherny_2026_tips`. Last checked 2026-11-08.
5. Shrivu Shankar's blog, https://blog.sshh.io. Good for: a heavy user's practice with every Claude Code feature, and the case against custom subagents. Read: `shankar_2025_every_feature`. Last checked 2026-11-08.
6. HumanLayer's blog, https://www.humanlayer.dev/blog. Good for: context files and the budget of instructions a model follows. Read: `humanlayer_2025_claude_md`. Last checked 2026-11-08.
7. Jesse Vincent's blog, https://blog.fsck.com, and his Superpowers skills. Good for: testing instructions on subagents under realistic pressure. Read: `vincent_2025_superpowers`. Last checked 2026-11-08.
8. Cognition's blog, https://cognition.com/blog. Good for: the case against splitting one task's context across agents. Read: `cognition_2025_multiagents` (no stored copy). Last checked 2026-11-05.
9. Chroma's research pages, https://www.trychroma.com/research. Good for: how quality falls as context grows. Read: `chroma_2025_contextrot` (no stored copy). Last checked 2026-11-05.
10. The Prompting Science Reports of Wharton's Generative AI Labs (arXiv). Good for: controlled tests of common prompting advice. Each names the models it tested, often older than those in use, so it is relied on only where it agrees with the model maker's documentation. Read: `basil_2025_personas`, `meincke_2025_cot`. Last checked 2026-11-08.
