# General price indices, read 2026-10-30

The index each jurisdiction's guidance names for bringing money to a price base year (the owner's rulings of 2026-10-30), read from each publisher by a research agent of an earlier session on 2026-10-30. The agent checked every value in the TOML files by script against the raw file it came from; its scripts stayed in the session's scratchpad, since they do not pass the strict type check. The session checked the United States series again against `raw/NipaDataA_A191RD.txt`: all 36 values agree. It then read the two workbooks for the United Kingdom and Australia with its own standard-library reader: all 72 United Kingdom values (financial years by column B and C, calendar years by H and I of the sheet named) and all 74 Australian values (Data1, by series ID and the date in column A) agree.

1. United States (`united_states.toml`): the GDP implicit price deflator, BEA NIPA Table 1.1.9 line 1, series A191RD, 1990 to 2025, 2017 = 100, from BEA's flat file (`raw/NipaDataA_A191RD.txt` keeps that series' lines). FRED did not answer; BEA's release index page answered 403, the file itself loaded.
2. United Kingdom (`united_kingdom.toml`): HM Treasury's "GDP deflators at market prices, and money GDP", October 2026 (Budget) edition, published 2026-10-29; financial years 1990-91 to 2025-26 (2025-26 = 100, ONS L8GG) and calendar years 1990 to 2025 (2025 = 100, ONS MNF2). The forecast years are given only as percentage changes and are not recorded. ONS YBGB, from an earlier vintage (2026-08-12, 2023 = 100), gives 107.7 for 2025 against 2023 where the Treasury file gives 107.5.
3. Australia (`australia.toml`): ABS 5206.0, June 2026 release (2026-09-02), financial years 1989-90 to 2025-26, 2023-24 = 100: the gross non-farm product implicit price deflator (A2304681A, Table 34), which the 2006 Handbook names as the default, and the GDP implicit price deflator (A2304682C, Table 36). The ABS Data API serves these only quarterly.

How these values enter the guidance editions, under which keys, and how the money conversion reads them is for the money conversion's brief, written whole in the new names.
