# 8 The topic guide

Section 8 of the `scope-case` skill, read when the analysis begins (`SKILL.md` 0.5); its numbers continue those of `SKILL.md`. Sources are the keys of `research/refs.toml` or the shared `library/refs.toml`, whose entries say how far each was read. "Held at" says where an answer is kept (11.2): the user's record, an organization's, or the analysis's; "user default" is a preference the user may set once and override in any analysis. The last column is fixed here, never judged in the conversation: "turn" where a wrong answer can change the result or a deliverable, otherwise the default the defaults turn lists (`SKILL.md` 0.7).
